# KS-900JP 関数電卓

ブラウザで動く数学自然表示の関数電卓です。カシオ ClassWiz CW シリーズ（fx-JP900CW 系）の取扱説明書で公開されている機能・仕様を参考に作りました。メーカーとは関係のない非公式のアプリです。

`index.html` をブラウザで開けば動きます。ビルドは不要です。QR コード表示だけは CDN のライブラリを使います。

## 機能

- **数学自然表示入出力**: 分数・帯分数・√・ⁿ√・累乗・logₐb・|x|・∫・d/dx・Σ・Π・循環小数を教科書どおりに入力できます。ライン表示入出力にも切り替えられます。
- **厳密計算**: 結果を有理数・平方根（2項まで）・π の形で保持し、`1/3+1/6 = 1/2`、`sin 75° = (√6+√2)/4`、`(1+√2)² = 3+2√2` のように表示します。
- **12の電卓アプリ**（HOME）
  - 基本計算（計算履歴・リプレイ、Ans/PreAns、マルチステートメント、真偽判別）
  - 統計計算（1変数/2変数、度数、回帰7種、四分位数、推定値 x̂ ŷ、P( Q( R( ▸t）
  - 分布計算（正規分布の確率密度/累積/逆関数、二項分布、ポアソン分布。リスト入力45件）
  - 表計算（45行×5列、相対/絶対参照、Min/Max/Mean/Sum、一括入力、コピー/切り取り、自動計算、1,700バイト制限）
  - 数表作成（f(x)/g(x)、最大30/45行）
  - 方程式/関数（連立2〜4元、2〜4次方程式の厳密解と極値、ソルバー）
  - 不等式（2〜4次）、複素数、n進計算（32ビット、論理演算）、行列（4×4、MatA〜D）、ベクトル（2/3次元、VctA〜D）、Math Box（サイコロ、コイントス、数直線、円・時計）
- **CATALOG**: 科学定数47種（CODATA 2018）、単位換算（尺貫法を含む）、周期表118元素の原子量、エンジニアリング記号、双曲線関数など
- **FORMAT**: 標準 / 小数 / 仮分数 / 帯分数 / ENG表記 / 素因数分解 / 60進数 / 循環小数 / 直交・極座標形式
- **SETTINGS**: 入力/出力、角度単位、Fix/Sci/Norm、エンジニアリング記号、分数表示、複素数表示、小数点、3桁区切り、コントラスト、オートパワーオフ、QRコードのバージョン、リセット

## 液晶フォント

液晶表示のドットフォント（`fonts/ksdot*.woff2`、`css/fonts.css`）は `tools/build_font.py` で DejaVu Sans Mono をドット化して生成しています。ライセンスは `fonts/LICENSE-DejaVu.txt` を参照してください。

## テスト

```
node test/core.test.js
```

## ファイル構成

- `js/core/` 厳密計算（exact）、値の型、数式エディタ、構文解析、評価、表示形式
- `js/data/` 科学定数・単位換算・元素データ
- `js/ui.js` メニュー・フォーム・計算画面などの共通UI
- `js/apps/` 各計算アプリ
- `js/main.js` キー配列・HOME・SETTINGS・電源
